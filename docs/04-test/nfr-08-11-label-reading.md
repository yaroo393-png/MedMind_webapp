ต้นฉบับเกณฑ์: `docs/02-requirements/spec.md` §4
- **NFR-08:** ร่างแสดงภายใน 10 วินาทีหลังส่งรูป ใน ≥ 18 จาก 20 ฉลากจริง บนมือถือผ่านลิงก์เว็บ
- **NFR-11:** ร่างชื่อยาตรงกับฉลาก ≥ 16 จาก 20 ฉลากจริง (ชุดเดียวกัน)
- ตรวจเพิ่ม: ชื่อผู้ป่วย/HN ไม่โผล่ในร่างหรือหน้าจอ (NFR-09 · SC-011)

> ผลทุกช่องต้องมาจากการวัดจริง · ห้ามจดชื่อผู้ป่วย HN หรือชื่อแพทย์ลงไฟล์นี้ · ห้าม commit รูปฉลากจริง (`real-labels/` git ไม่เก็บ)

## วิธีวัด

1. ตั้ง GitHub Pages ให้เสิร์ฟ branch ที่มี FR-02 (Settings → Pages) · เปิดดู `…/prototype/src/screens/medication.js` ต้องไม่ได้ 404
2. มือถือ: เปิด `https://yaroo393-png.github.io/MedMind_webapp/prototype/?role=caregiver` · อีกเครื่อง (หรือแท็บ) `?role=senior` · จับคู่ (FR-01)
3. ใบที่ 1 อ่านครั้งแรกจะช้ากว่าเพราะโหลดตัวอ่าน (~12 MB) → จดแยกในช่องหมายเหตุ · ใช้ Wi-Fi เดียวกันตลอด
4. แต่ละใบ: กด "เพิ่มยาจากฉลาก" → ถ่ายรูป → **เริ่มจับเวลาเมื่อกดยืนยันรูป** → **หยุดเมื่อเห็นร่าง** (หรือข้อความอ่านไม่ได้)
5. เทียบช่องชื่อยาในร่างกับฉลาก: ตรงทุกตัวอักษรที่สำคัญ (ชื่อยา + ความแรง) = ✓ · ว่าง/ผิด = ✗
6. กด "ยกเลิก" (ไม่ต้องบันทึก) แล้วทำใบถัดไป
