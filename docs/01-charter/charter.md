  - โพสต์ Facebook/Pantip ที่พูดถึงการลืมกินยา · รีวิว 1–2 ดาวของแอปเตือนยา → ยังไม่ได้เก็บ (ไม่จำเป็นต่อเกณฑ์ M1 เพราะมีผู้ใช้จริงชั้น B ครบ 3 คนแล้ว)
- **ชั้น B (ผู้ใช้จริง):** 3 คนในส่วนที่ 1 ข้อ 2

### 2.2 5 Whys (ร่างจากผลสัมภาษณ์ · ทีมตรวจว่าตรงกับที่ได้ยินจริง)
1. ทำไมผู้สูงอายุจำไม่ได้ว่ากินยาแล้วหรือยัง? → เพราะนาฬิกาปลุกเตือนได้ แต่พอปิดเสียงแล้วไม่มีอะไรบันทึกว่ากินแล้ว (ผู้ให้สัมภาษณ์ 1)
2. ทำไมผู้ดูแลต้องโทรถาม? → เพราะไม่มีช่องทางที่บอกสถานะการกินยาให้ผู้ดูแลเห็นเอง (ผู้ให้สัมภาษณ์ 2)
3. ทำไมการโทร/LINE ยังไม่พอ? → เพราะผู้ดูแลทำงาน ติดประชุมก็โทรไม่ได้ และต้องถามซ้ำ ~5–6 ครั้ง/สัปดาห์ (ผู้ให้สัมภาษณ์ 2)
4. ทำไมผู้สูงอายุไม่ใช้แอปบันทึกเอง? → เพราะต้องสมัครบัญชีและกรอกข้อมูลเอง ซึ่งไม่สะดวก อยากให้ลูกตั้งค่าให้ (ผู้ให้สัมภาษณ์ 3)
5. ทำไมลูกตั้งค่าให้ยังยาก? → เพราะต้องกรอกข้อมูลยาเองด้วยมือ ผู้ให้สัมภาษณ์ 2 จึงอยาก "ถ่ายรูปฉลากยาแล้วช่วยกรอกข้อมูล" (อนุมานจากคำตอบนี้ ไม่ได้ถามตรง ๆ ว่ายากเพราะอะไร)

**Root cause:** ไม่มีเครื่องมือที่ผูก "เตือน → ยืนยัน → สถานะ" ของแต่ละมื้อยาเข้าด้วยกัน โดยผู้สูงอายุไม่ต้องตั้งค่าเอง
และผู้ดูแลรู้สถานะได้โดยไม่ต้องโทรถาม

### 2.3 Litmus test 5 ข้อ

| 2 | เกิดบ่อยแค่ไหน | ทุกมื้อยาของทุกวัน · ผู้ดูแลถาม ~5–6 ครั้ง/สัปดาห์ | ผ่าน |
| 3 | วิธีเดิมแย่พอไหม | นาฬิกาปลุก/กล่องยาไม่บอกสถานะ · โทรไม่ติดตอนประชุม | ผ่าน  |

| 5 | ซอฟต์แวร์ทำให้ดีขึ้นอย่างมีนัยสำคัญไหม | ระบบแจ้งผู้ดูแลเฉพาะมื้อที่ยังไม่ยืนยันเมื่อถึง T+15 โดยไม่ต้องมีใครโทร · ร่างข้อมูลยาจากรูปฉลากแทนการพิมพ์ | ผ่าน |
