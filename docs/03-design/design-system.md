# Design System — MedMind v2

ต้นฉบับค่าทั้งหมดของหน้าจอ · โค้ดอยู่ที่ `prototype/src/ui/tokens.css` (ค่า) และ `prototype/src/ui/app.css` (components)
กติกา: หน้าจอใช้ token เท่านั้น ห้ามใส่สี/ขนาดเป็นตัวเลขตรง ๆ · เปลี่ยนสีต้องคำนวณ contrast ใหม่ทุกครั้ง (NFR-03 · LESSONS-FROM-V1)

**ทิศทาง:** อ่านง่ายสำหรับผู้สูงอายุก่อนความสวย — ตัวใหญ่ ปุ่มใหญ่ สีเน้นสีเดียว พื้นอุ่นแบบกระดาษ ไม่มี gradient ไม่มีเงาบนการ์ด ไม่ใช้ emoji แทน icon
**Reference (AI เสนอ · ทีมยืนยันแทน D 22/10/69):** หน้ายาของแอปสุขภาพในโทรศัพท์ (iOS Health → Medications) — 3 อย่างที่เขาทำและเรานำมาใช้:
1. หนึ่งมื้อ = หนึ่งหน้า ยาทุกตัวของมื้อเรียงเป็นการ์ด แล้วปุ่มยืนยันเดียวด้านล่าง (BR-09, BR-10)
2. สถานะใช้คำ + สีพื้นอ่อน ไม่ใช้สีอย่างเดียว (BR-14 · ผู้ตาบอดสีอ่านได้)
3. ตัวเลขเวลาใช้ตัวเลขความกว้างเท่ากัน (tabular) ทำให้เวลาในรายการตรงกัน

### 1.2 ตัวอักษร (ฟอนต์เดียว)
- `--font-sans`: Leelawadee UI (Windows) · Thonburi (iOS/macOS) · Sukhumvit Set · Noto Sans Thai (Android) · Tahoma
  — ใช้ฟอนต์ที่มีในเครื่อง เพราะ prototype ต้องเปิดด้วยดับเบิลคลิกได้โดยไม่ต่ออินเทอร์เน็ต
- ขนาด: `--text-sm` 18 (ขั้นต่ำ NFR-03) · `--text-md` 20 · `--text-lg` 24 (ชื่อยา NFR-03) · `--text-xl` 28 (ชื่อหน้าจอ) · `--text-2xl` 40 (เวลามื้อ · รหัส 6 หลัก)
- น้ำหนัก 400 / 700 · บรรทัด 1.25 (หัวข้อ) / 1.5 (เนื้อความ)

### 1.3 ระยะ — สเกล 4 · 8 · 16 · 24 · 32
`--space-1` 4 · `--space-2` 8 · `--space-3` 16 · `--space-4` 24 · `--space-5` 32

### 1.4 ขนาดเป้าแตะ
`--tap-primary` 64 px (ปุ่ม "กินแล้ว"/"ยังไม่กิน" กว้างเต็มจอ · NFR-03) · `--tap-min` 48 px (ปุ่มและช่องกรอกอื่น)

### 1.5 มุม เส้น เงา
มุม 8 / 12 / 24 / 32 (กรอบโทรศัพท์) · เส้น 1 px (ตกแต่ง) / 2 px (ช่องกรอก ปุ่ม) · วงโฟกัส 3 px สี ink ·
เงามีที่เดียวคือกรอบโทรศัพท์ (การ์ดไม่มีเงา) · ผู้ใช้ตั้ง "ลดการเคลื่อนไหว" → ปิด transition

### 1.6 ข้อยกเว้น: แถบทดลอง (demo bar)
แถบด้านบนใช้สาธิตเวลาจำลอง (ADR นาฬิกาจำลอง ใน `architecture.md`) ไม่ใช่หน้าจอของแอป → ตัวอักษร 14 px (`--text-demo`) และปุ่มสูง 32 px
ได้รับยกเว้นจาก NFR-03 · ยังใช้ token และผ่าน contrast 4.5:1 · มีข้อความบนแถบว่า "แถบนี้ใช้สาธิตเท่านั้น ไม่ใช่ส่วนของแอป"

## 2. Components (`app.css`)

| Component | Class | State / variant | ใช้กับ |
|---|---|---|---|
| ปุ่ม | `.btn` + `--primary` / `--secondary` / `--danger` / `--ghost` · `--xl` (64 px) · `--block` | ปกติ · hover/กด (accent-strong) · `:disabled` (พื้น sunken ตัวอักษร muted) · โฟกัส (วง ink 3 px) | ทุก FR · `--xl` = FR-04 |
| การ์ด | `.card` · `.card__title` (24 px) | — | ยาแต่ละตัว (FR-03) · มื้อ (FR-05) |
| ช่องกรอก | `.field` · `.field__label` · `.field__input` · `.field__hint` · `.field__error` | ปกติ · โฟกัส · `.field--invalid` (ขอบแดง + ข้อความ "กรุณาตรวจสอบ") | ร่างจากฉลาก (FR-02 BR-04) · รหัส 6 หลัก (FR-01) |
| ป้ายสถานะ | `.status--taken` / `--alerting` / `--unconfirmed` / `--waiting` | คำตาม BR-14 เสมอ (สีเป็นตัวช่วย ไม่ใช่ตัวสื่อหลัก) | FR-05 · หน้าแรก Senior (FR-04) |
| แถบแจ้ง | `.banner--info` / `--warn` / `--danger` | — | ข้อควรระวัง (FR-03) · อ่านฉลากไม่ได้ (FR-02 ✗5) |
| สถานะว่าง | `.empty` · `.empty__title` | — | ยังไม่มีมื้อยา (FR-03 ✗5, FR-05 ✗4) |
| Toast | `ctx.toast(msg, tone)` · `app.toast(role, msg, tone)` | `success` / `danger` / ปกติ · หายเองใน 4 วินาที · อ่านด้วย screen reader (`aria-live`) · อยู่ใต้หัวจอ ไม่บังปุ่มล่าง | feedback ทุกการกระทำ · แจ้งผู้ดูแล (FR-05) |
| แถบยกเลิก 10 วินาที | `.banner--info` + `.stack` · ข้อความผล + ปุ่ม `btn--secondary` "ยกเลิก" (≥ 48 px) · `MedMind.reminder.undoBanner()` | หายเมื่อครบ 10 วินาที (เวลาจริง) หรือแตะใหม่ | S2, S3 (FR-04 R1b · แทน dialog เพราะ 1 แตะ NFR-02) · ไม่มีคู่สีใหม่ |
| Dialog ยืนยัน | `ctx.confirm({ title, message, confirmLabel, tone })` → `Promise<boolean>` | `tone: 'danger'` → โฟกัส "ยกเลิก" ก่อน · Esc/แตะพื้นหลัง = ยกเลิก | การกระทำที่ย้อนไม่ได้: ยกเลิกการจับคู่ (BR-17) · ล้างข้อมูล |
| มื้อบนหน้าเตือน | `.session` (กลุ่มมื้อ · มื้อถัดไปคั่นด้วยเส้น `--color-line-strong`) · `.session-time` (`--text-2xl`) | กำลังเตือน (`.status--alerting`) · เลยเวลา (`.status--unconfirmed`) · "กินแล้ว" primary เฉพาะมื้อแรก (1 ปุ่มหลักต่อหน้าจอ) | S2 (FR-03 BR-16) · เพิ่มโดย A แทน C 24/10/69 แจ้ง D · ไม่มีคู่สีใหม่ |
| กรอบภาพกล้องสด | `.scanner` (สี่เหลี่ยมจัตุรัส กว้างเต็มจอ · ขอบ `--border-input`) | — | C1 (FR-01 ✓3) · เพิ่มโดย A 22/10 แจ้ง D |
| QR + รหัสเชิญ | `.qr` (กรอบ canvas `--qr-size` 240 px) · `.invite-code` (`--text-2xl` เว้นวรรค 3+3) · `.field__input--code` | QR สีจาก `--color-ink` บน `--color-surface` (contrast 16.54:1 · คำนวณ 22/10) | S1, C1 (FR-01 ✓1) · เพิ่มโดย A 22/10/69 แจ้ง D |
| ตัวเลือกแบบแตะ | `.choices` (fieldset) · `.choice` (label + radio/checkbox สูง ≥ 48 px) | เลือกแล้ว = ขอบ/พื้น accent · `.field--invalid` = ขอบแดง | C2 เวลาตามฉลาก/มื้อ (FR-02) · เพิ่มโดย A 23/10 แจ้ง D |
| ซ่อน | `[hidden]` ชนะ `display` ของ component เสมอ | — | ทุกหน้าจอ · เพิ่มโดย A 23/10 |
| ป้าย Covers | `.covers` (หัวจอทุกหน้า) | สร้างจาก `covers` ของหน้าจอ | constitution หลักการ I |
| โทรศัพท์ + แท็บ | `.phone` · `.stage__tabs` | จอ ≥ 861 px เห็น 2 เครื่อง · จอเล็กสลับด้วยแท็บ · `?role=senior` / `?role=caregiver` = เครื่องเดียวต่อหน้า (ไม่มีแท็บ) | SRS §2.2 |
