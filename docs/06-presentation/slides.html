PROCESS + AI · ai-use-statement.md

AI ร่าง คนตรวจและตัดสิน

กระบวนการ

  • Agile 1 Must FR = 1 increment ผ่าน Spec Kit
  • specify → clarify (ถามคน) → plan → tasks → analyze → implement
  • test ก่อนโค้ด · 1 งาน = 1 branch + PR

AI ผิด แล้วจับได้ด้วยอะไร

  • test ค่าขอบ → บั๊กตรรกะ 2 ตัว
