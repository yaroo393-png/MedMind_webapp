## R-0 ข้อมูลจริงที่ใช้ออกแบบ (23/10/69)

ผู้ใช้ส่งรูปฉลากจริง 4 ใบ (โรงพยาบาลเดียวกัน ยา 4 ชนิด) · เก็บใน `real-labels/` ที่ git ไม่เก็บ · **ไม่คัดลอกชื่อผู้ป่วย/HN/ชื่อแพทย์ลงไฟล์ใดใน repo**
ลองอ่านด้วย OCR แบบเปิดไฟล์ตรง (`file://`) ใน Chrome เดสก์ท็อป ด้วยวิธีใน R-1 — ผลจริง (ไม่ใช่การวัด NFR-08/11 ซึ่งต้องใช้ 20 ใบบนมือถือ):

| ใบ | ลักษณะ | ผล OCR (ข้อความดิบไม่แสดง) | เวลา |
|---|---|---|---|
| 1 | ยาเม็ด ก่อนนอน + คำเตือน | อ่านบรรทัดยาครบ: ชื่อยา+`[15]` · `ครั้งละ 1 เม็ด` · `ก่อนนอน` · `ยานี้อาจทำให้ง่วงนอน` | 2.5 วินาที |
| 2 | ผงเกลือแร่ (ซอง) "ดื่มบ่อยๆ" | อ่านได้ แต่ `ซอง→ของ`, `น้ำ→นํา` · เป็นยาที่ไม่รองรับ (BR-07) | 4.2 วินาที |
| 3 | ยาเม็ด ก่อนอาหาร เช้า-กลางวัน-เย็น ไม่ระบุนาที | อ่านได้ แต่ `เช้า→เข้า`, `วันละ→รวันละ` · ไม่มีนาที = ตรง AC ✗10 | 4.0 วินาที |
| 4 | ซองสีน้ำตาล ถ่ายเอียง คำบนฉลากถูกรอยยับบัง | **อ่านไม่ได้เลย** = ตรง AC ✗5 | 1.5 วินาที |

**ข้อค้นพบ:**
- รูปแบบฉลาก: ชื่อยาเป็นบรรทัดภาษาอังกฤษตัวใหญ่ที่มี `[จำนวนจ่าย]` · ขนาด "รับประทานครั้งละ N เม็ด" · เวลา "วันละ N ครั้ง ก่อน/หลังอาหาร เช้า กลางวัน เย็น" หรือ "ก่อนนอน" · บรรทัดสรรพคุณ (ไม่ใช้) · คำเตือนขึ้นต้น "ยานี้…"
- บรรทัดส่วนตัวบนฉลาก: ชื่อผู้ป่วย · HN/เลขใบสั่ง · ชื่อแพทย์ · วันที่ · และฉลากมี **QR ของโรงพยาบาลเอง** (ตัวจับคู่ FR-01 ไม่รับเพราะไม่ใช่ `MEDMIND:`)
- **OCR ทำคำนำหน้าและ "HN" เพี้ยน** (`HN→LN/HIN`, `น.พ.→UW.`) → วิธี "หาบรรทัดชื่อ/HN แล้วตัดทิ้ง" พลาดได้จริง (ดู R-3)

**ผลในแอปจริงหลัง implement (23/10/69 · Chrome เดสก์ท็อป ดับเบิลคลิก · ไม่ใช่ผลวัด NFR):** ใบ 1 ร่างครบ (ก่อนนอน 1 เม็ด + คำเตือน) · ใบ 2 แจ้ง "ระบบยังไม่รองรับยาเมื่อมีอาการ" ·
ใบ 3 ก่อนอาหาร 3 มื้อ ช่องนาที "กรุณาตรวจสอบ" · ใบ 4 แจ้งอ่านไม่ได้ + ฟอร์มว่าง · **ชื่อผู้ป่วย/HN/แพทย์ปรากฏบนจอและใน storage 0 ครั้งทั้ง 4 ใบ** ·
เวลา: ครั้งแรก 8.8 วินาที (รวมเตรียมตัวอ่าน) ครั้งต่อไป 3.0–7.6 วินาที

## R-1 อ่านฉลากเมื่อเปิดด้วยดับเบิลคลิก (ADR-08 · R11) — **ตัดสินแล้ว 23/10 (A: อาจารย์ต้องการดับเบิลคลิก)**

- **Decision:** ฝังไฟล์ที่ OCR ต้องโหลด (ข้อมูลภาษาไทย/อังกฤษ, core, worker) เป็นไฟล์ `.js` ที่เก็บข้อมูลเป็น base64 ใน `prototype/vendor/tesseract-embed/`
  (สร้างด้วยสคริปต์ `prototype/tools/embed-ocr.js` จากไฟล์ใน `vendor/tesseract/` ที่ไม่ถูกแก้) → `readLabel` โหลดไฟล์เหล่านี้**เฉพาะครั้งแรกที่ผู้ดูแลส่งรูป** (แทรก `<script>`) ·
  สร้าง worker จาก blob ของ core + worker · แก้บั๊ก Tesseract.js 5.1.1 ในหน่วยความจำ (`t.data` → `t.code` ในโค้ด worker ตอนโหลด ไม่แก้ไฟล์ vendor)
- **Rationale:** `file://` บล็อก `fetch`/`importScripts` ของไฟล์ข้างเคียง แต่ `<script src>` ใช้ได้ · พิสูจน์แล้ว 22/10 (ข้อความทดสอบ) และ 23/10 (รูปจริง R-0) ·
  โหลดเมื่อใช้ → หน้าเปิดเร็วเท่าเดิม ไม่โหลด ~12 MB ถ้าไม่ได้อ่านฉลาก · ใช้ core แบบไม่ใช้ SIMD เพื่อให้รันได้ทุกเครื่อง
- **Consequence:** repo ใหญ่ขึ้น ~12 MB · วิธีแก้บั๊กผูกกับรุ่น 5.1.1 (`readLabel` ตรวจว่าแทนที่ได้จริง ไม่ได้ → `UNSUPPORTED_PAGE` + กรอกเอง) · ครั้งแรกรอโหลดเพิ่ม
- **Alternatives:** GitHub Pages อย่างเดียว (ปฏิเสธ: อาจารย์ต้องการดับเบิลคลิก) · Live Server (ปฏิเสธ: ผู้ตรวจต้องติดตั้งเพิ่ม) · OCR บน cloud (ปฏิเสธ: ADR-03, NFR-09) ·
  ฝังไว้ใน `index.html` โหลดทุกครั้ง (ปฏิเสธ: เปิดหน้าช้าทั้งที่ส่วนใหญ่ไม่ได้อ่านฉลาก)

## R-2 ตัวแยกข้อความ: รับเฉพาะสิ่งที่รู้จัก ทนคำเพี้ยน

- **Decision:** `parseLabel(text)` ทำให้ข้อความเป็นรูปเดียวกันก่อน (NFC · `ํา`→`ำ` · ช่องว่างซ้ำ) แล้วหารูปแบบเฉพาะ 5 แบบ:
  1. **ชื่อยา**: ตัวอักษรละตินตัวใหญ่ (มีตัวเลข/จุด/ขีดได้) ตามด้วย `[ตัวเลข]` → ชื่อ = ส่วนก่อน `[` · หน่วยหลัง `]` (เม็ด/แคปซูล/ซอง/ขวด…)
  2. **ขนาด**: `ครั้งละ <จำนวน> <หน่วย>` · จำนวนเต็ม ≥ 1 + เม็ด/แคปซูล = รองรับ · ครึ่ง/½/ทศนิยม = `HALF_TABLET` · ซอง/ช้อน/มล./ซีซี/ขวด = `NOT_TABLET`
  3. **เวลา**: `ก่อนอาหาร` / `หลังอาหาร` / `ก่อนนอน` · มื้อ: `เช้า` (รับ `เข้า` เพราะ OCR เพี้ยนบ่อย — R-0) · `กลางวัน`/`เที่ยง` · `เย็น` · นาที: `<N> นาที` หรือ `ครึ่งชั่วโมง` (= 30 ตามที่เขียนบนฉลาก)
  4. **ยาเมื่อมีอาการ / ไม่มีเวลาแน่นอน**: `เมื่อมีอาการ` · `เวลามีอาการ` · `เมื่อปวด` · `เมื่อมีไข้` · `ทุก N ชั่วโมง` · `บ่อยๆ` → `AS_NEEDED`
  5. **คำเตือน/ข้อห้าม**: บรรทัดที่ขึ้นต้น `ยานี้` หรือมี `ระวัง` → ข้อควรระวัง · มี `ห้าม` → ข้อห้ามใช้
- ขัดกันเอง (ทั้งก่อนและหลังอาหาร · ก่อนอาหารพร้อมก่อนนอนในยาเดียว) → `timing = null` + "กรุณาตรวจสอบ" (BR-04 ห้ามเดา)
- คำที่ถูกบัง (`…งอาหาร` ใบ 4 ในรูปตรง) → ไม่ตรงทั้งก่อน/หลัง → `timing = null` ไม่เดา
- **Alternatives:** ใช้ AI ตีความข้อความ (ปฏิเสธ: Out of scope "AI แนะนำยา" + ส่งข้อมูลออกนอกเครื่อง NFR-09 + เดาได้) · แก้คำผิดด้วยพจนานุกรมใหญ่ (ปฏิเสธ: เดาเกินฉลาก ขัด BR-04)

## R-3 ไม่อ่านชื่อผู้ป่วย / HN เข้าระบบ (NFR-09 · R10b · clarify 23/10)

- **Decision:** **รับเฉพาะ (whitelist)** — ช่องของร่างมาจาก 5 รูปแบบใน R-2 เท่านั้น บรรทัดอื่นทั้งหมดถูกทิ้ง ·
  ชื่อยาต้องเป็นตัวละตินตัวใหญ่ + `[ตัวเลข]` จึงไม่มีทางเป็นชื่อคนภาษาไทย · ข้อความดิบไม่แสดงบนหน้าจอและไม่เก็บ (ตัวแปรใน `readLabel` → `parseLabel` แล้วทิ้ง) ·
  ร่างที่ได้มีเฉพาะช่องตาม data model ไม่มีช่อง "ข้อความดิบ"
- **Rationale:** R-0 พิสูจน์ว่า OCR ทำ `HN` และคำนำหน้าชื่อเพี้ยน → **ตัดทิ้งตามรายการห้าม (blacklist) พลาดได้** · whitelist ปลอดภัยกว่าโดยโครงสร้าง
- **Test:** ข้อความตัวอย่างที่มีบรรทัดชื่อผู้ป่วย HN แพทย์ วันที่ (ทั้งแบบถูกและแบบที่ OCR เพี้ยน) → `JSON.stringify(draft)` ไม่มีชื่อ/เลข HN เลย (SC-011)
- **Alternatives:** blacklist คำนำหน้า/HN (ปฏิเสธ: R-0) · ปิดส่วนบนของรูปก่อนอ่าน (ปฏิเสธ: ตำแหน่งต่างกันทุกโรงพยาบาล)

## R-4 อ่านไม่ได้ = ✗5

- **Decision:** `readLabel` ล้มเหลว (โหลด OCR ไม่ได้ = `UNSUPPORTED_PAGE` · ถอดรหัสรูปไม่ได้/ไม่มีข้อความ = `UNREADABLE`) **หรือ** `parseLabel` หาไม่ได้แม้แต่ช่องเดียว
  (`found = 0` — เช่นใบ 4) → แจ้งสาเหตุ + เปิดฟอร์มว่างให้กรอกเอง · ไม่ใช่หน้า error
- อ่านเกิน 10 วินาที → แสดง "กำลังอ่านฉลาก…" + ปุ่ม "กรอกเอง" ใช้ได้ระหว่างรอ (NFR-08 วัดจริงไม่ตัดการทำงาน)

## R-5 เวลาเตือน (BR-06 · clarify 23/10)

- **Decision:** `reminderTimes(med, mealTimes)` = หลังอาหาร → เวลามื้อ · ก่อนอาหาร → เวลามื้อ − N · ก่อนนอน → เวลาเข้านอน · เรียงเวลา ไม่ซ้ำ ·
  ผลใดตกก่อน 00:00 → `null` (ไม่สร้าง) และ `validateDraft` คืน `BEFORE_MIDNIGHT` + มื้อนั้น · ข้อมูลไม่พอ → `null`
- เวลาเตือนเป็นค่าคำนวณ ไม่เก็บ (กติกาวิชา) · FR-03 เรียกฟังก์ชันนี้

## R-6 ลบยา (BR-03 · clarify 23/10)

- **Decision:** `removeMedication(list, medicationId)` คืนรายการใหม่ · หน้าจอยืนยันด้วย `ctx.confirm({ tone: 'danger' })` · ยาที่ลบไม่มีเวลาเตือนเพราะเวลาเตือนคำนวณจากรายการยา ·
  ประวัติการยืนยันของมื้อที่ผ่านมาคงอยู่ (ไม่ใช่ข้อมูลของยาตัวนั้นโดยตรง — `DOSE_CONFIRMATION` ผูกกับมื้อ)

## R-7 ฉลากตัวอย่าง (clarify 23/10)

- **Decision:** `prototype/samples/` = รูปฉลากที่สร้างเองด้วย canvas จากรูปแบบใน R-0 · ชื่อผู้ป่วย/แพทย์/HN เป็นค่าสมมติที่เห็นชัด (เช่น "ผู้ป่วย ตัวอย่าง", HN `000000000`) ·
  ชื่อยาเป็นยาสามัญทั่วไป · 4 ใบ: ก่อนนอน+คำเตือน · ก่อนอาหารไม่ระบุนาที · หลังอาหาร เช้า-เย็น · ยาเมื่อมีอาการ · ข้อความของฉลากตัวอย่างใช้เป็น fixture ใน test ด้วย
- รูปฉลากจริงอยู่ใน `real-labels/` (git ไม่เก็บ) ใช้ทดสอบมือและวัด NFR เท่านั้น
